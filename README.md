# 供应商报价整理工具（单文件离线版）

纯前端单页工具：上传供应商报价表（xlsx / xls / csv），自动识别商品名称、品牌、规格、包装、条码与多列价格，按折扣核算折后价，导出汇总表（CSV / XLSX）。

表格解析库已内嵌进 `index.html`，**离线可用，不依赖任何 CDN**；所有解析与计算都在浏览器本地完成，不上传数据。

## 本地使用

双击 `index.html`，用浏览器打开即可；点击「选择文件」上传报价表。

- 基准价列：默认按优先级取集采价，可在下拉框切换为顺丰代发价、控价/活动价、代发价、市场/零售价等列。
- 折扣：按「几折」输入，10 = 原价，8 = 八折。
- 搜索：按名称 / 品牌 / 规格 / 条码筛选，导出内容为当前筛选后的全部记录。

## 识别规则（基于样表归纳）

- 表头自动扫描前 10 行定位；不同工作表列顺序、表头写法不一致均可适配。
- 价格文本自动抽数值，兼容 `19.9元/袋`、`46.5元/3袋`、`39/2袋` 等写法。
- 同一商品多规格跨多行时，名称 / 品牌 / 条码自动沿用上一行。
- 纯类目字典表、备注表识别为 0 条。

## 部署到 GitHub Pages

1. 把 `index.html`（连同本 README）放在仓库 `main` 分支根目录。
2. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main`、目录 `/(root)`，保存。
3. 等待 1–3 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 边界与限制

- 字段识别基于表头关键词，个别特殊表头可能识别不到，导出后建议人工核对。
- 数据只保留在当前浏览器会话，刷新页面后需重新上传。
- 价格自动提取数字，文本字符会被忽略；不校验价格合理性。
